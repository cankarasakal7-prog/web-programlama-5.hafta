# 📌 GÖREV 1: DEFTERE YAZILACAK (Sınav Konuları)

### 1. JavaScript Nedir?
Web sayfalarına mantık, karar verme yeteneği ve kullanıcı ile etkileşim katan programlama dilidir.

### 2. DOM (Document Object Model)
JavaScript'in HTML etiketlerine müdahale edebilmesi için oluşturulan ağaç yapısıdır. 
`document.getElementById("Kutu")` kodu, HTML'deki ID'si "Kutu" olan elemanı bulup yakalamamızı sağlar.

### 3. `var` / `let` (Değişkenler)
Bilgisayarın geçici hafızasında veri (sayı, metin vb.) saklayan kutulardır.

### 4. `if` / `else`
Karar yapısıdır. Şart doğruysa (`if`) bir kodu, yanlışsa (`else`) başka bir kodu çalıştırır.

### 5. `switch` - `case`
Bir değişkenin alabileceği **ÇOK FAZLA** seçenek (durum) varsa, `if-else` yerine daha düzenli olan bu komut kullanılır. İşlem bitince `break;` ile çıkılır.

### 6. `return`
Bir fonksiyonun görevini bitirdikten sonra, kendisini çağıran yere bir değer "geri döndürmesi" işlemidir.
